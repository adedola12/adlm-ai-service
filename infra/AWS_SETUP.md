# AWS credentials setup (one-time)

Two different credentials exist in this system — don't mix them up:

- **AWS access keys** — let the service call Bedrock/Textract. Local dev only;
  the deployed Lambda uses its execution role instead (no keys in prod).
- **ADLM licence token** — lets a *caller* use the AI API (the `ai`
  entitlement). Generated by ADLM Cloud login, or `scripts/make-dev-token.js`
  for testing.

## 1. Bedrock model access (mostly automatic now)

The old "Model access" page is retired — serverless foundation models
auto-enable on first invoke. Two caveats:

- **Anthropic models**: the first invoke may require a one-time use-case form.
  If `test-meter.js` fails with a use-case/access message, open
  **Bedrock → Model catalog → Claude Haiku → open in Playground**, send one
  message, submit the form once, and rerun.
- **Service Control Policies**: if this account is in an AWS Organization, an
  SCP can deny Bedrock. A deny mentioning `...:root` usually just means "stop
  using the root user" — the IAM user below fixes it. If the IAM user is
  *also* denied, the SCP must be edited from the organization's management
  account (**AWS Organizations → Policies → Service control policies**).

## 2. Create the IAM user (local dev keys)

1. AWS Console → **IAM** → **Users** → **Create user** → name:
   `adlm-ai-dev` → no console access.
2. **Attach policies directly** → **Create policy** → JSON tab → paste
   `infra/iam-policy.json` → name it `AdlmAiBedrockTextract` → attach it.
3. Open the user → **Security credentials** → **Create access key** →
   use case "Local code" → copy the **Access key ID** and **Secret access key**
   (shown once).

## 3. Put the keys in `.env`

```
AWS_REGION=us-east-1
AWS_ACCESS_KEY_ID=AKIA................
AWS_SECRET_ACCESS_KEY=........................................
```

`src/config/index.js` loads `.env` before the AWS clients are constructed, so
both SDKs pick these up automatically. `.env` is gitignored — the keys never
enter the repo. If a key ever leaks, deactivate it in IAM immediately.

## 4. Verify

```
npm run seed:pricing        # once — writes PricingRate + CreditAccount
node scripts/test-meter.js  # calls Bedrock through meterAiCall, prints the cost
```

When you later `sam deploy`, delete nothing: the Lambda gets the same
permissions from `template.yaml`'s role policy and ignores your local keys.
